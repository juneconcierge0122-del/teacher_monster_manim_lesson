## 這一節在做什麼

**前六節一直缺一個乘法。** 第 1 到第 5 節把交錯張量建起來、第 6 節拿它做出行列式，
可是兩個交錯張量的張量積幾乎從來不是交錯的——一乘就離開那個空間。
這一節補的就是這件事，辦法很直接：乘完之後，用第 5 節那個投影打回來。

**定理 7.1** 讓那個辦法成立：

```
Ω ( f ⊗ g )   =   Ω ( f ⊗ Ω g )   =   Ω ( Ω f ⊗ g )
```

證明是把和重新分組。把 ρ 看成只動後面 l 個位置，那麼每一個 σ ′ 恰好來自 l 階乘組配對
`{ ⟨ ρ , ρ ⁻ ¹ σ ′ ⟩ : ρ ∈ S ₗ }`，除掉那個階乘就回到原來的和。
**它的用處是讓「先打回交錯」可以隨時插進乘法裡而不改變答案**，後面每一步都靠它。

**楔積的定義**（書頁 316）：

```
f  ∧  g   =   C ( n + l , n )   Ω ( f ⊗ g )
```

那個二項係數是為了讓後面的公式不帶多餘的階乘。**引理 7.1** 把好幾個接起來：

```
f ₁ ∧ ⋯ ∧ f ₖ   =   ( n !  /  n ₁ ! ⋯ n ₖ ! )  Ω ( f ₁ ⊗ ⋯ ⊗ f ₖ )
```

**推論**把第 5 節那組基底收了回來。一階的情形係數就是 n 階乘：

```
λ ₁ ∧ ⋯ ∧ λ ₙ   =   n !  Ω ( λ ₁ ⊗ ⋯ ⊗ λ ₙ )
μ q ₁ ∧ ⋯ ∧ μ q ₙ   =   n ! Ω ( μ ( q ) )   =   ν ( q )
```

所以第 5 節辛苦建出來的那組基底，現在只是「對偶基底的楔積」。

**定理 7.2** 是分次交換律：

```
g  ∧  f   =   ( − 1 ) ˡ ⁿ   f  ∧  g            λ  ∧  λ   =   0
```

把後面 l 個位置一個一個搬到前面 n 個位置之前，要 l 乘 n 次對換。
**推論**：一組一形式楔起來等於零，恰好就是它們線性相依。
**引理 7.2** 說楔積雙線性，一行就證完，但下一條定理要靠它。

**定理 7.3（延拓定理）** 是這一節的重點：

```
θ  :  ⟨ λ ₁ , … , λ ₙ ⟩   ↦   λ ₁ ∧ ⋯ ∧ λ ₙ            F   =   G  ∘  θ
```

任何一個 `( V * ) ⁿ` 上的交錯 n 重泛函都唯一地從 θ 穿過去，變成 `𝒜 ⁿ` 上的一個**線性**泛函。
書上說硬算會寫得很繁，改用維數：`d ( 𝒜 ⁿ ( V * ) ) = C ( m , n ) = d ( 𝒜 ⁿ ) = d ( ( 𝒜 ⁿ ) * )`，
而那個對應是單射，所以是同構。**這等於說楔積是所有交錯映射裡最普遍的那一個。**

接著書上用它把 `Δ ( T * ) = Δ ( T )` 重證一次，而且不用任何座標：

```
T * λ ₁ ∧ ⋯ ∧ T * λ ₙ  ( ξ )   =   λ ₁ ∧ ⋯ ∧ λ ₙ  ( T ξ ₁ , … , T ξ ₙ )
```

固定一組 ξ 得到交錯 n 重泛函 `ev ξ`，兩邊各提出一個 Δ，而 `ev ξ ≠ 0`，於是兩個 Δ 相等。

**引理 7.3** 收尾：不是零的楔積叫**多重向量**，

```
μ ₁ ∧ ⋯ ∧ μ ₙ   =   k  ( λ ₁ ∧ ⋯ ∧ λ ₙ )        ⟺        兩組張出同一個子空間
```

書上說這表示多重向量與它所張的子空間的關係，就像一個向量與它所張的那條線。

## 這一集用的例子

**顯示用的值與檢查用的值不共用任何程式碼。** 螢幕上的楔積是照書上的定義建的——張量積，
對 S ₙ 求和配正負號做反對稱化，再乘二項係數；對照用的是 `numpy.linalg.det` 與
`numpy.linalg.matrix_rank`。兩邊的橋是這條恆等式：

```
( λ ₁ ∧ ⋯ ∧ λ ₙ ) ( ξ ₁ , … , ξ ₙ )   =   det [ λ ᵢ ( ξ ⱼ ) ]
```

所以螢幕上那個反對稱化的和，是拿一個**完全不排列任何東西**的分解法來核的。
畫面上的例子用小整數，三階行列式可以手算；另外帶一組固定亂數種子的隨機族，
用在那些「剛好湊巧相等會蓋掉正負號錯誤」的恆等式上。

| 要驗的事 | 結果 |
|---|---|
| 交錯的 f 真的交錯、而 `f ⊗ g` 真的不交錯 | 0.0e+00 對 8.000 |
| 投影之後又回到交錯 | 0.0e+00 |
| **定理 7.1**，四組階數各驗兩欄 | ( 1,1 ) ( 2,1 ) ( 1,2 ) ( 2,2 ) 殘差全部 ≤ 2.2e−16 |
| 楔積的二項係數在一階時就是推論的 n 階乘 | 0.0e+00 |
| **獨立對照**：`( λ ₁ ∧ λ ₂ ) ( ξ ₁ , ξ ₂ )` vs 二階行列式 | 都是 +3（Gram 是 `[[1,2],[−1,1]]`） |
| **獨立對照**：三個一形式的楔積 vs 三階行列式 | 都是 +9，差 1.8e−15，而且是整數 |
| 那個楔積自己也是交錯的 | 0.0e+00 |
| **引理 7.1** 四組階數，係數各不相同 | ( 1,1,1 )→6、( 2,1,1 )→12、( 1,2,1 )→12、( 2,2,1 )→30，殘差 ≤ 4.0e−15 |
| **定理 7.2** 四組階數，兩種正負號都出現 | −1 , +1 , +1 , −1，殘差 ≤ 4.4e−16 |
| `λ ∧ λ = 0` | 精確的 0.0e+00 |
| **相依恰好等於零**：`λ ₃` 換成 `2 λ ₁ − 3 λ ₂` | 楔積 0.0e+00，獨立算的 rank 是 2 |
| 對照的獨立那一組 | 楔積最大分量 2，rank 3 |
| **引理 7.2** 左右兩邊各驗一次 | 0.0e+00 與 4.4e−16 |
| **定理 7.3**：六個 `ν ( q )` 在六個代表元上的值 | **就是 6 × 6 單位矩陣**，rank 6 = C ( 4 , 2 ) |
| `Δ ( T * ) = Δ ( T )`（4 × 4 整數矩陣） | 都是 +32 |
| 恆等式 ( \* ) 的兩邊，以及兩邊都等於 `Δ ( T ) · ev ξ` | +544 = 32 × 17，殘差 ≤ 4.5e−13 |
| `ev ξ ≠ 0`（否則約不掉） | +17 |
| **引理 7.3**：`μ ᵢ = Σ c ᵢ ⱼ λ ⱼ`，k 應該是 `det ( c )` | k = +12，殘差 1.1e−14 |
| **反過來也要有效**：換一組跨出子空間的 | 與任何純量倍差 3.000，rank 3 對 4 |

最後一列是這一集唯一真正有風險的地方：**只驗「同一個子空間 ⇒ 成比例」是半條引理**，
所以另外取一組跨出去的，確認它的楔積與原來那個不成比例。
