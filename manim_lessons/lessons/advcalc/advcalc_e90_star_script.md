## 這兩節在做什麼

**兩節各只有一頁多，但它們是同一件事。** §8 替外冪裝上純量積，§9 把它花掉。

起點是 V 上一個**非退化的對稱雙線性形式**。書上明講：即使它不是正定的，
這一節與下一節照樣把它叫做純量積。非退化讓 `y ↦ ȳ`（其中 `ȳ ( x ) = ( x , y )`）
成為 V 到 V\* 的同構，於是 V\* 上也有一個純量積。

**公式 8.1** 把它搬到外冪上：

```
( ū ₁ ∧ ⋯ ∧ ū q ,  v̄ ₁ ∧ ⋯ ∧ v̄ q )   =   det  ( ū ᵢ , v̄ ⱼ )
```

**這個定義要靠上一集的定理 7.3 才站得住**：固定 v̄ 那一半，右邊對 ū 那一半是交錯多重線性的，
所以唯一地延拓成 `𝒜 q ( V * )` 上的線性函數；兩邊都做一次就得到雙線性。
對稱性從行列式本身看得出來。

**公式 8.2** 取一組好的基底（第 2 章定理 7.1 保證存在）：

```
( u ᵢ , u ⱼ )   =   ±  δ ᵢ ⱼ
```

負號的個數就是書上那個 `#`。**公式 8.3** 說外冪上那組基底也是正交的：

```
( ū ᵢ , ū ⱼ )   =   ±  δ ᵢ ⱼ
```

指標組不同時，一定有某個指標只出現在其中一邊，那個矩陣就整條橫列是零；
相同時對角線是 ±1、其餘是零，行列式就是對角元的乘積。**公式 8.4** 是最高次冪：

```
( u ₁ ∧ ⋯ ∧ u ₙ ,  u ₁ ∧ ⋯ ∧ u ₙ )   =   ( − 1 ) ^ #
```

**§9 從「最高次冪是一維的」出發。** 導出的純量積非退化，所以每個非零元素自乘都同號，
於是恰好有兩個元素是單位的，彼此差一個負號。**選定其中一個就是替 V 選一個定向**（公式 9.1）。

**星算子**（公式 9.2）：拿 `v̄ ∈ 𝒜 q` 去楔 `ȳ ∈ 𝒜 ⁿ ⁻ q`，結果落在那個一維空間裡，
所以 `v̄ ∧ ȳ = f v̄ ( ȳ ) · ū`，而 `f v̄` 是線性的。互補那一層的純量積非退化，
所以那個泛函一定是「與某個唯一元素作內積」：

```
( ȳ , ∗ v̄ )  ū   =   v̄  ∧  ȳ
```

基底上的樣子（公式 9.3）：指標組有共同元素就楔成零（上一集「因式重複就是零」的直接後果），
互補時 `ū ᵢ ∧ ū ⱼ = ε k ū`，所以

```
∗  ū ᵢ   =   ±  ε i ₁ … i q j ₁ … j ₙ ₋ q   ū ⱼ
```

那個 ± 就是 8.3 裡 `ū ⱼ` 帶的號。最後兩條：

```
∗ ∗ v̄   =   ( − 1 ) q ( n − q ) ⁺ #  v̄              ( ∗ v , ∗ w )   =   ( − 1 ) ^ #  ( v , w )
```

## 這一集用的例子

**特徵取成三正一負，不是隨便挑的。** 全正的話 `#` 等於零，公式 9.4 與 9.5 的正負號
會全部塌成加一，每一條恆等式都變成「等於自己」，**正負號寫錯也看不出來**。
取 `σ = ( + , + , + , − )` 之後 `# = 1`，9.4 的指數是 `q ( n − q ) + # = 5`、號是負一，
9.5 的號也是負一，三對自乘值真的都翻號。

**顯示用的值與檢查用的值不共用任何程式碼。** 星算子建了兩次：一次是照公式 9.2
拿互補那一層的每個基底元素去解那個定義式（`star_solve`），一次是照公式 9.3
把 ε 與 8.3 的正負號讀出來、**完全不解方程**（`star_formula`）。
純量積也算了兩次：一次是 `numpy.linalg.det` 算兩兩相乘的矩陣，一次是 8.3 說它在這組基底下
必須長成的對角形式。

| 要驗的事 | 結果 |
|---|---|
| 形式對稱、非退化 | `det ( u ᵢ , u ⱼ ) = −1`，rank 4 |
| 公式 8.1 對 u 與 v 對稱 | 0.0e+00 |
| **獨立對照**：8.1 的行列式 vs 對角形式，逐格 | 0.0e+00 |
| **公式 8.3**：六個指標組兩兩的純量積 | 非對角 0.0e+00；對角 `[+1,+1,−1,+1,−1,−1]`，全部是 ±1 |
| 二階外冪裡負號的個數（與 n 的那個不同） | 3（而 `#` 是 1） |
| 指標組不同時那條整列是零 | `( 1 2 )` 對 `( 2 3 )`（只共用一個指標）的矩陣上面那列全零，det 0 |
